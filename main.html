Offshore Historical Weather & Sea-State Analysis¶

Historical operating conditions for two offshore locations using ERA5 Copernicus reanalysis (hourly, Jan 2021 – Dec 2025).

Location Coordinates Approx. position
West Coast 33°45'N, 119°45'W ~70 NM west of Los Angeles
Northeast Coast 40°00'N, 70°00'W ~180 NM east of New York

Metrics: significant wave height (SWH), 10 m wind speed (proxy for sustained wind), WMO Douglas sea states (exclusive), and dual operating criteria (SWH ≤ 6 ft / 1.8 m and wind ≤ 25 kt).

def classify_sea_state(swh_m: pd.Series) -> pd.Series:
    """
    Assign each hour an exclusive WMO Douglas sea-state label based on wave height.

    Input:  swh_m — Series of significant wave heights in meters (one value per hour)
    Output: Series of labels: 'SS2', 'SS3', 'SS4', 'SS5+', or 'SS0-1' (calm, < 0.1 m)

    Exclusive = each hour falls in exactly ONE bucket (not cumulative).
    """
    # Boolean masks for each sea-state range (WMO Douglas scale)
    conditions = [
        (swh_m >= 0.1) & (swh_m < 0.5),    # SS2: 0.1–0.5 m  (~0.3–1.6 ft)
        (swh_m >= 0.5) & (swh_m < 1.25),   # SS3: 0.5–1.25 m (~1.6–4.1 ft)
        (swh_m >= 1.25) & (swh_m < 2.5),   # SS4: 1.25–2.5 m (~4.1–8.2 ft)
        swh_m >= 2.5,                       # SS5+: ≥ 2.5 m   (~≥ 8.2 ft)
    ]
    choices = ["SS2", "SS3", "SS4", "SS5+"]
    # np.select picks the first True condition; default='SS0-1' for waves below 0.1 m
    return pd.Series(np.select(conditions, choices, default="SS0-1"), index=swh_m.index)


def load_monthly_file(path: Path, lat: float, lon: float) -> pd.DataFrame:
    """
    Load ONE monthly ERA5 zip file and return hourly wind + wave data at the target point.

    Input:  path — e.g. west_coast/era5_west_coast_2021_01.nc
            lat, lon — exact coordinates to interpolate to
    Output: DataFrame with ~744 rows (one per hour in the month), columns:
            valid_time, wind_kt, swh_m, swh_ft, sea_state, month, year
    """
    # Create a temp folder that auto-deletes when done (avoids cluttering disk)
    with tempfile.TemporaryDirectory() as tmpdir:
        # Unzip the .nc file — inside are two NetCDF files (wind + waves)
        with zipfile.ZipFile(path) as zf:
            zf.extractall(tmpdir)

        tmp = Path(tmpdir)
        # oper = 10 m wind components (u=east-west, v=north-south) on ~0.25° grid
        oper = xr.open_dataset(tmp / "data_stream-oper_stepType-instant.nc")
        # wave = significant wave height (swh) on ~0.5° grid
        wave = xr.open_dataset(tmp / "data_stream-wave_stepType-instant.nc")

        # Bilinear interpolation: estimate value at exact lat/lon (between grid points)
        u = oper["u10"].interp(latitude=lat, longitude=lon, method="linear")
        v = oper["v10"].interp(latitude=lat, longitude=lon, method="linear")
        swh = wave["swh"].interp(latitude=lat, longitude=lon, method="linear")

        # Convert xarray time coordinate to pandas datetime
        times = pd.to_datetime(oper["valid_time"].values)
        # Wind speed from components: speed = sqrt(u² + v²), still in m/s
        wind_ms = np.sqrt(u.values ** 2 + v.values ** 2)
        # Extract wave height values as plain float array
        swh_m = swh.values.astype(float)

        # Build hourly table for this month
        df = pd.DataFrame(
            {
                "valid_time": times,                  # Timestamp of each hour
                "wind_kt": wind_ms * MS_TO_KT,        # Wind speed converted to knots
                "swh_m": swh_m,                       # Significant wave height in meters
            }
        )

        # Close NetCDF files to free memory
        oper.close()
        wave.close()

    # --- Derived columns added after temp dir is cleaned up ---
    df["swh_ft"] = df["swh_m"] * M_TO_FT              # Wave height in feet
    df["sea_state"] = classify_sea_state(df["swh_m"])  # SS2/SS3/SS4/SS5+ label
    df["month"] = df["valid_time"].dt.month            # 1–12 (for grouping by calendar month)
    df["year"] = df["valid_time"].dt.year              # 2021–2025 (for year-over-year analysis)
    return df


def load_location(name: str, cfg: dict) -> pd.DataFrame:
    """
    Load ALL monthly files (60 total = 5 years × 12 months) for one location.

    Input:  name — 'West Coast' or 'Northeast Coast'
            cfg  — entry from LOCATIONS dict (lat, lon, dir, prefix)
    Output: DataFrame with ~43,824 rows (5 years of hourly data), sorted by time
            Prints progress every 12 files loaded.
    """
    data_dir = ROOT / cfg["dir"]  # e.g. ./west_coast/
    # Regex to parse year and month from filename: era5_west_coast_2021_01.nc
    pattern = re.compile(rf"{cfg['prefix']}_(\d{{4}})_(\d{{2}})\.nc$")
    # Find all matching .nc files and sort chronologically
    files = sorted(data_dir.glob(f"{cfg['prefix']}_*.nc"))

    if not files:
        raise FileNotFoundError(f"No files found in {data_dir}")

    frames = []       # List to collect each month's DataFrame
    total = len(files)
    for i, path in enumerate(files, start=1):
        match = pattern.match(path.name)
        if not match:
            continue  # Skip files that don't match expected naming pattern
        year, month = int(match.group(1)), int(match.group(2))
        # Load and interpolate this month's data to the target point
        df = load_monthly_file(path, cfg["lat"], cfg["lon"])
        df["file_year"] = year    # Year from filename (for reference)
        df["file_month"] = month  # Month from filename (for reference)
        df["location"] = name     # 'West Coast' or 'Northeast Coast'
        frames.append(df)
        # Print progress: once per year (every 12 files) and at the end
        if i % 12 == 0 or i == total:
            print(f"  {name}: loaded {i}/{total} files")

    # Stack all months into one long table, sorted chronologically
    hourly = pd.concat(frames, ignore_index=True).sort_values("valid_time")
    # Remove any duplicate timestamps (safety check)
    hourly = hourly.drop_duplicates(subset=["valid_time"], keep="first")
    return hourly


def monthly_summary(hourly: pd.DataFrame, location: str) -> pd.DataFrame:
    """
    Pool all 5 years by calendar month and compute climatology statistics.

    Input:  hourly — full hourly DataFrame for one location (~43,824 rows)
            location — 'West Coast' or 'Northeast Coast'
    Output: DataFrame with 12 rows (one per month), columns include:
            averages, sea-state %, operating-criteria %

    Comparison logic:
      - All January hours (2021–2025) are grouped together, same for each month
      - pct_ss2/ss3/ss4/ss5_plus: exclusive % of hours IN each sea state
      - pct_hs_le_6ft:     % hours where waves alone are ≤ 1.8 m (6 ft)
      - pct_wind_le_25kt:  % hours where wind alone is ≤ 25 kt
      - pct_both_criteria: % hours where BOTH wave AND wind limits met simultaneously
    """
    rows = []
    for month in range(1, 13):  # Loop Jan(1) through Dec(12)
        # Filter to this calendar month across all years
        subset = hourly[hourly["month"] == month]
        n = len(subset)  # Total hours (typically ~3,600–3,720 per month × 5 years)
        if n == 0:
            continue

        # Exclusive sea-state percentages: what fraction of hours fall in each bucket
        ss_counts = subset["sea_state"].value_counts(normalize=True) * 100
        # Boolean masks for operating criteria (True = condition met)
        hs_ok = subset["swh_m"] <= HS_LIMIT_M       # Wave ≤ 6 ft?
        wind_ok = subset["wind_kt"] <= WIND_LIMIT_KT  # Wind ≤ 25 kt?
        both_ok = hs_ok & wind_ok                     # BOTH at the same hour?

        rows.append(
            {
                "location": location,
                "month": month,
                "month_name": MONTH_NAMES[month - 1],
                "n_hours": n,
                "avg_swh_m": subset["swh_m"].mean(),       # Mean wave height (m)
                "avg_swh_ft": subset["swh_ft"].mean(),      # Mean wave height (ft)
                "avg_wind_kt": subset["wind_kt"].mean(),    # Mean wind speed (kt)
                "max_swh_m": subset["swh_m"].max(),         # Worst wave in this month
                "max_wind_kt": subset["wind_kt"].max(),       # Strongest wind in this month
                "pct_ss2": ss_counts.get("SS2", 0.0),        # % hours in SS2 (0.1–0.5 m)
                "pct_ss3": ss_counts.get("SS3", 0.0),        # % hours in SS3 (0.5–1.25 m)
                "pct_ss4": ss_counts.get("SS4", 0.0),        # % hours in SS4 (1.25–2.5 m)
                "pct_ss5_plus": ss_counts.get("SS5+", 0.0),  # % hours in SS5+ (≥ 2.5 m)
                "pct_ss0_1": ss_counts.get("SS0-1", 0.0),    # % hours calm (< 0.1 m)
                "pct_hs_le_6ft": hs_ok.mean() * 100,          # % hours: wave OK alone
                "pct_wind_le_25kt": wind_ok.mean() * 100,     # % hours: wind OK alone
                "pct_both_criteria": both_ok.mean() * 100,      # % hours: BOTH OK (key metric)
            }
        )

    summary = pd.DataFrame(rows)
    # Round averages to 2 decimal places for readability
    for col in ["avg_swh_m", "avg_swh_ft", "avg_wind_kt", "max_swh_m", "max_wind_kt"]:
        summary[col] = summary[col].round(2)
    # Round all percentage columns to 1 decimal place
    for col in summary.columns:
        if col.startswith("pct_"):
            summary[col] = summary[col].round(1)
    return summary

def rank_favorable_months(summary: pd.DataFrame, location: str, top_n: int = 3) -> pd.DataFrame:
    """
    Rank and display the best months for offshore operations at a given location.

    Input:  summary — 12-row monthly summary from monthly_summary()
            location — site name for the print header
            top_n — how many top months to show (default 3)
    Output: DataFrame ranked 1, 2, 3 with key stats for each top month
            Also prints and displays the ranked table.

    Comparison: months are ranked by pct_both_criteria (highest = most favorable).
    """
    ranked = (
        summary.sort_values("pct_both_criteria", ascending=False)  # Best months first
        .head(top_n)[  # Keep only top N
            ["month_name", "pct_both_criteria", "pct_hs_le_6ft", "pct_wind_le_25kt", "avg_swh_ft", "avg_wind_kt"]
        ]
        .reset_index(drop=True)
    )
    ranked.index = ranked.index + 1  # Rank starts at 1 instead of 0
    ranked.index.name = "rank"
    print(f"\nTop {top_n} favorable months — {location} (by % meeting both criteria):")
    display(ranked)  # Output: table showing rank, month, and operating stats
    return ranked

6. Conclusions & Observations¶

Run the comparison cell above for exact computed values. Key findings from the 2021–2025 ERA5 analysis:

West Coast (33°45'N, 119°45'W)¶

  • Most favorable months: August (96.6%), July (96.5%), and September (96.1%) — nearly all hours meet both SWH ≤ 6 ft and wind ≤ 25 kt criteria.
  • Shoulder season: June and October–November remain strong (83–88%), giving a broad operating window from late spring through fall.
  • Challenging period: March is the least favorable month (60.3%), driven by higher winds (avg ~14 kt) and more frequent SS4/SS5+ conditions from North Pacific swell.
  • Sea-state profile: SS3 and SS4 dominate year-round (typical for open ocean). SS2 is essentially absent (<0.1%) — calm glassy seas are rare offshore. SS5+ occurs in winter months (~4–11% of hours Dec–Mar) but drops to near zero Jun–Sep.

Northeast Coast (40°00'N, 70°00'W)¶

  • Most favorable months: July (90.3%), June (89.9%), and August (84.9%) offer the best dual-criteria availability.
  • Shoulder season: May (~81%) and September (~71%) are viable but with more exposure to SS5+ than the West Coast.
  • Challenging period: January (36.9%) and February (38.1%) are severely constrained by nor'easter-season winds (avg ~17–18 kt) and large swell (avg SWH 7.5–8.0 ft). November–December and March also fall below 52%.
  • Sea-state profile: SS5+ is common in winter (31–39% of hours Jan–Feb, 33% in Dec) — materially more exposed than the West Coast. Even summer months see occasional SS5+ events (1–4%).

Head-to-head¶

The West Coast offers substantially more favorable conditions year-round, with a longer calm season, fewer extreme sea states, and ~27% more annual operating hours.

Data caveats¶

  1. ERA5 reanalysis — gridded model output, not in-situ buoy measurements. Local conditions may differ from observations.
  2. 5-year sample (2021–2025) — captures recent climate but may not represent full multi-decade variability. Consider extending to 1991+ for a 30-year climatology.
  3. 10 m wind as sustained wind proxy — ERA5 hourly 10 m wind is commonly used but is not identical to marine anemometer sustained winds at platform height.
  4. Spatial interpolation — values are bilinearly interpolated from ~0.25° (wind) and ~0.5° (waves) grids to the exact point.
  5. WMO Douglas SS2 — the 0.1–0.5 m band is rarely observed at open-ocean offshore points; SS3–SS5+ carry most of the distribution.

Ideas for further analysis¶

  • Percentile stats (P50/P90/P95) by month for engineering design loads
  • Weather windows — longest consecutive hours/days meeting both criteria
  • Wind rose diagrams — directional wind distribution by season
  • Storm exceedance — catalog of SS5+ and SS6+ events with dates and duration
  • NDBC buoy validation — compare ERA5 against buoy 46025 (Southern CA) and 44008 (NE Atlantic)
  • Extended climatology — download ERA5 back to 1991 for a robust 30-year baseline
  • Joint probability matrix — 2D histogram of SWH vs wind to identify which constraint binds more often
